# 代码来源

本笔记使用的代码全部来自你上传的 `v5.1.2.zip`，主要对应：

| 内容 | 源码工程 |
|---|---|
| HelloWorld | `0_HelloWorld` |
| LED | `1_LED`、`2_FlowingLED` |
| 蜂鸣器 | `3_Beep` |
| 按键 | `4_Key` |
| 多任务 | `5_Multitask` |
| EXTI | `6_Exti` |
| LCD 调试 | `7_LCDDisplay` |
| GPTimer | `8_GPTimer` |
| esp_timer | `9_ESPTimer` |
| PWM | `10_PWM` |
| 舵机 | `11_PWMServoMotor` |
| ADC oneshot | `12_ADC` |
| ADC continuous | `12_ADCContinuous` |
| I2C / BH1750 | `14_IICBH1750` |
| UART | `15_Uart`、`15_UartPro` |
| SPI / LCD | `16_SPILCD` |
| TF 卡 | `17_SPISDCard`、`18_SDCardPicture` |
| 摄像头 | `19_Camera` |
| SPIFFS | `21_SPIFFS` |
| Wi-Fi STA | `22_WIFI_STA` |
| Wi-Fi AP | `23_WIFI_AP` |
| SNTP | `24_NTCTime` |
| BLE | `25_BLE` |

为了不把本地 Wi-Fi 密码复制到笔记中，`wifista.h` / `wifiap.h` 中的具体凭据值没有展开；其余代码块均保持上传文件原样。LCD 图片数组等纯静态大数据也不重复嵌入笔记，但驱动函数与 `app_main()` 已摘出。
