## 时序

**UART：空闲高 → Start=0 → 数据低位先行 → Stop=1。**  
**I2C：空闲高高；SCL低时改 SDA；SCL高时读 SDA；START=高时 SDA↓；STOP=高时 SDA↑；ACK=0。**  
**SPI：CS↓开始；CPOL 决定空闲电平；CPHA 决定采样/移出边沿；每个时钟同时收发。**

## 常见问题

| 现象 | 优先检查 |
|---|---|
| GPIO 不动 | IO 号、模式、低/高有效、板载占用 |
| 按键多触发 | 消抖、上下拉、等待松手逻辑 |
| EXTI 不进 | `intr_type`、ISR service、handler add、intr enable |
| Timer 周期错 | `resolution_hz`、alarm_count、单位 µs |
| PWM 不对 | freq、resolution、duty、channel/timer、GPIO |
| ADC 错 | channel、atten、frame 格式、数据解析索引 |
| UART 乱码 | 9600/数据位/停止位/电平标准/TX-RX 交叉 |
| I2C NACK | 地址 0x46/0x47 的 R/W 位、SCL/SDA、上拉、100 kHz |
| SPI 不通 | CS、Mode、SCK/MOSI/MISO、设备句柄 |
| TF 挂载失败 | FAT32、SPI2、CS=IO2、sdkconfig 长文件名配置 |
| Wi-Fi 没 IP | NVS、netif、event loop、STA 凭据、GOT_IP 事件 |
| BLE 扫不到 | NimBLE 是否 sync、是否已开始广播、GAP fields |

## 源码差异

- BH1750：PPT 通用主读最后一个字节要求 NACK；上传 `bh1750.c` 两个字节都使用 `I2C_MASTER_ACK` 后 STOP。笔记保留源码，不偷偷改。
- 舵机：`motor.c` 注释把 90° 写成 `0.75`，PPT 和公式对应 `0.075`。
- SPI：`spi2_transfer_byte()` 源码写 `t.length = data * 8`；笔记按上传文件原样保留。
