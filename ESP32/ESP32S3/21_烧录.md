## 两种方式

**开发：源码工程 + VS Code / ESP-IDF → 编译 → 下载 → 调试。**  
**量产：提前编译出 `.bin` → Flash Download Tool → 串口/USB 下载到芯片。**

这样生产部门只需要固件和烧录参数，不必拿完整源代码工程，也不必配置整套开发环境。

ESP-IDF 一个工程通常不只有 app 一个镜像，实际 Flash Tool 需要按工程编译结果填写对应 `.bin` 与地址。因此烧录失败或烧录后不能启动时，优先检查 **芯片型号、端口、bin 是否齐全、地址是否匹配当前工程的 partition / bootloader 配置**。

这一章没有对应 `v5.1.2` 示例工程，因此没有伪造代码。
