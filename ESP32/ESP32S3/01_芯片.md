# 芯片

## 结构

ESP32-S3 的核心不是“一个 CPU + 几个 IO”，而是 **CPU、片上存储、无线数字电路、RTC、安全模块和大量外设通过内部总线连接**。课程使用的核心板基于 ESP32-S3-WROOM-1-N16R8：N16 表示 16 MB Flash，R8 表示 8 MB PSRAM；芯片本身是 Xtensa LX7 双核，最高 240 MHz，片上 SRAM 512 KB、ROM 384 KB。

![[assets/ppt_009.png|900]]

*PPT：ESP32-S3 内部结构。*

芯片、模组、开发板要分开：**芯片**是 MCU 本体；**模组**把芯片、Flash/PSRAM、天线及必要外围封装到一起；**开发板**再把供电、USB 转串口、按键、接口等做成便于开发的板子。

## GPIO Matrix

ESP32-S3 的 IO 不是像很多 MCU 一样完全固定外设复用，而是先经过 IO MUX / GPIO 交换矩阵，再连接 UART、I2C、SPI 等外设。因此很多外设信号可以映射到不同 GPIO。

![[assets/ppt_018.png|900]]

*PPT：IO MUX + GPIO 交换矩阵。*

要注意“可映射”不等于“任何脚都能随便用”。开发板上的某些 IO 已经连接了 Flash、PSRAM、USB、按键、LCD、摄像头等；真正分配引脚时先看底板原理图。

## 电平

课程所有普通数字 IO 都按 3.3 V 逻辑理解：**高电平约 3.3 V，低电平约 0 V**。上拉的作用是没人驱动时给出默认高电平，下拉则给出默认低电平。

## 启动

Strapping 引脚会在上电启动时被采样。课程 PPT 给出的启动模式中，GPIO0 与 GPIO46 共同参与：

| 模式 | GPIO0 | GPIO46 | 作用 |
|---|---:|---:|---|
| SPI Boot | 1 | 任意 | 正常从 Flash 读取程序启动 |
| Download Boot | 0 | 0 | 通过 USB / UART0 下载固件 |

![[assets/ppt_024.png|900]]

*PPT：SPI Boot 与 Download Boot。*

ESP32-S3 还有 CPU 复位、内核复位、系统复位、芯片复位等不同级别。JTAG 则用于内部测试 / 调试，课程强调正常情况下可使用 USB 串口 / 内部 JTAG 控制器，异常情况下也可接外部 JTAG 调试器。
