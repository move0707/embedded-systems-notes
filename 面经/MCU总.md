1、SPI
SPI 是怎么传输的？
```
SPI 是同步全双工通信。主机先通过 CS 选中从机，然后产生 SCK 时钟，MOSI 用来主机发送，MISO 用来主机接收。本质上双方通过移位寄存器，在每个时钟下逐位移出和移入数据，所以发送和接收可以同时进行。通信双方还要约定 CPOL、CPHA 和 MSB/LSB 位序。
```
SPI 四种模式是什么？
```
四种模式由 CPOL 和 CPHA 两位组合出来。CPOL 决定 SCK 空闲电平，0 是低、1 是高(空闲时候是高还是低)；CPHA 决定在哪个时钟边沿采样，0 是第一个边沿采样，1 是第二个边沿采样，所以组合起来就是 Mode 0 到 Mode 3。
```
`CS 选从机，SCK 提供时钟，MOSI/MISO 负责双向数据；CPOL/CPHA 决定时钟模式；MSB/LSB 决定从高位还是低位开始传。`


2、IIC
```
I²C 是同步串行、半双工通信，通过 SCL 和 SDA 两根信号线通信，可以连接多个设备。主机通过 START 发起通信，发送从机地址和读写位，从机应答后传输数据，最后通过 STOP 结束。I²C 使用开漏输出，所以总线需要上拉电阻。
```

3、FreeRTOS 
FreeRTOS 里的 tick 是什么？双MCU的 STM32 和 ESP32 工程里，1 个 tick 分别是多少时间？
```
tick 是 FreeRTOS 的系统时间节拍，不是 CPU 主频时钟。内核通过 tick 计数实现延时和超时。我的 STM32 工程 1 tick 是 1 ms，ESP 工程 1 tick 是 10 ms。
```

`vTaskDelay()` 和 `vTaskDelayUntil()` 有什么区别？为什么你的 10 ms 电机控制任务更适合用 `DelayUntil`？
```
vTaskDelay() 是从当前时刻开始相对延时，会把任务执行时间叠加进去；vTaskDelayUntil() 是按照固定的绝对节拍唤醒，更适合周期任务。我的电机控制任务要求 10 ms 固定周期，所以使用 delay-until 思路。
```
`vTaskDelay()`：**从现在开始等多久**  
`vTaskDelayUntil()`：**等到下一个固定时间点**

4、UART、SPI、I²C、CAN 有什么区别？
```
UART 一般是点对点、异步通信，简单、调试方便；
SPI 是同步通信，速度高，通过 CS 选择不同从机；
I²C 也是同步通信，只需要 SCL 和 SDA 两根线，通过地址区分多个设备，速度一般比 SPI 低；
CAN 是多节点总线通信，支持仲裁和错误检测，抗干扰能力更强，但还需要 CAN 收发器和终端电阻。
```

5、CAN
```
CAN 是汽车电子常用的多节点总线通信协议，通过 CAN_H 和 CAN_L 两根差分信号线传输。不同报文通过 ID 区分，并通过仲裁机制决定发送优先级，通常 ID 数值越小，优先级越高。CAN 还支持 CRC 校验、错误检测和自动重发，可靠性比较好。使用时还需要 CAN 收发器和终端电阻。
```
