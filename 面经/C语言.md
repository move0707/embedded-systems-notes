1、static
```
static 局部变量只初始化一次，生命周期贯穿整个程序运行过程，但作用域仍然只在函数内部。

void func(void)
{
    static int count = 0;
    count++;
    printf("%d\n", count);
}


如果这个函数连续调用3次，返回3



static 有两个常见作用。修饰局部变量时，让变量具有静态存储期，只初始化一次，可以保留上次函数调用的值；修饰文件作用域的变量或者函数时，限制它们只能在当前源文件内部使用。
```

2、栈和堆
```
栈 Stack：跟着函数调用自动申请、自动释放。
堆 Heap：程序运行时自己申请，用完自己释放。
栈：自动分配自动释放；堆：动态申请手动释放。栈怕溢出，堆怕泄漏和碎片。

栈是随着函数调用自动管理的，主要保存局部变量、函数调用现场和返回地址，空间比较有限；堆是运行时通过分配器动态申请和释放的，生命周期更灵活，但需要注意申请失败、内存泄漏和碎片。FreeRTOS 里面每个任务还有自己独立的任务栈，动态创建任务和队列等对象会使用堆。
```

局部变量、全局变量、static 变量分别放哪里?
```
普通局部变量通常放在栈上；全局变量和 static 静态变量放在静态存储区，已初始化的通常在 data 段，未初始化的通常在 bss 段。malloc 动态申请的内存在堆上。static 局部变量虽然只能在函数内部访问，但生命周期是整个程序运行期间。
```

3、`const` 和 `volatile`
```
const 是只读限定，防止通过对应变量修改数据；
volatile 是告诉编译器变量可能被外部因素改变，每次都需要实际访问，不能随意优化掉。嵌入式里通常用于硬件寄存器或者可能被中断修改的变量。
```

4、`p`、`*p`、`&a` 分别代表什么？
```

- `p`：指针变量，保存 `a` 的地址。
    
- `*p`：解引用，取得 `p` 指向的变量的值，也就是 `10`。
    
- `&a`：取地址，得到变量 `a` 的内存地址。
  
```

5、函数
sizeof 和 strlen 有什么区别？
```
sizeof 是运算符，得到对象或类型占用的字节数；strlen 是函数，计算字符串长度，不包含末尾的`\0`。
```
memcpy 和 memmove 有什么区别？
```
memcpy 负责复制内存，但要求源区域和目标区域不重叠；memmove 允许内存区域重叠。
```


6、结构题
什么是结构体内存对齐？
```
编译器通常会根据成员类型的对齐要求安排结构体成员的位置，可能在成员之间或末尾加入填充字节，提高内存访问效率。
```

7、指针
什么是野指针和悬空指针？
```
编译器通常会根据成员类型的对齐要求安排结构体成员的位置，可能在成员之间或末尾加入填充字节，提高内存访问效率。
```
什么是函数指针和回调函数？
```
函数指针就是保存函数地址的指针；回调函数就是把函数传给其他模块，让对方在合适的时机调用。
```
