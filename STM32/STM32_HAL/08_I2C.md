## START / STOP

![START STOP](https://doc.embedfire.com/mcu/stm32/f103/hal_general/zh/latest/_images/image8.jpeg)

**SCL 高时 SDA 1→0：START**  
**SCL 高时 SDA 0→1：STOP**

## 数据有效

![数据有效性](https://doc.embedfire.com/mcu/stm32/f103/hal_general/zh/latest/_images/image9.jpeg)

普通数据阶段：

**SCL 低：允许 SDA 改变**  
**SCL 高：SDA 必须稳定，用于采样**

## ACK

![ACK NACK](https://doc.embedfire.com/mcu/stm32/f103/hal_general/zh/latest/_images/image11.jpeg)

第 9 个时钟：

**SDA=0 → ACK**  
**SDA=1 → NACK**

## CubeMX

路径：

**Connectivity → I2C1**

Mode：

`I2C`

参数重点：

- Clock Speed；
- Duty Cycle；
- Addressing Mode；
- Own Address（主机通常不重点用）。

F103 默认 I2C1 常见：

`PB6=SCL，PB7=SDA`

是否重映射取决于实际芯片/引脚配置。

## 初始化

```c
I2C_HandleTypeDef hi2c1;

hi2c1.Instance = I2C1;
hi2c1.Init.ClockSpeed = 100000;
hi2c1.Init.DutyCycle = I2C_DUTYCYCLE_2;
hi2c1.Init.OwnAddress1 = 0;
hi2c1.Init.AddressingMode =
    I2C_ADDRESSINGMODE_7BIT;

HAL_I2C_Init(&hi2c1);
```

## Master 发送

```c
HAL_I2C_Master_Transmit(
    &hi2c1,
    DEV_ADDR,
    tx,
    len,
    1000
);
```

对应：

`S → Addr+W → Data... → P`

## Master 接收

```c
HAL_I2C_Master_Receive(
    &hi2c1,
    DEV_ADDR,
    rx,
    len,
    1000
);
```

## 寄存器读写

传感器、EEPROM 最常用：

```c
HAL_I2C_Mem_Write(...)
HAL_I2C_Mem_Read(...)
```

例如 MPU6050：

```c
#define MPU6050_ADDR (0x68 << 1)

HAL_I2C_Mem_Read(
    &hi2c1,
    MPU6050_ADDR,
    0x75,
    I2C_MEMADD_SIZE_8BIT,
    &data,
    1,
    1000
);
```

HAL 内部替你完成：

`START → 地址写 → Reg → ReSTART → 地址读 → Data → STOP`

## 地址坑

如果手册写 7 位地址 `0x68`，HAL 的 DevAddress 通常按地址字段位置传：

```c
0x68 << 1
```

不要把：

`7位地址 0x68`

和：

`总线上地址字节 0xD0/0xD1`

混在一起。

## MemAddressSize

```c
I2C_MEMADD_SIZE_8BIT
I2C_MEMADD_SIZE_16BIT
```

这是**从机内部寄存器/存储地址宽度**，不是从机地址位数。

## 设备检测

```c
HAL_I2C_IsDeviceReady(
    &hi2c1,
    DEV_ADDR,
    3,
    100
);
```

非常适合 I2C 扫描。

## IT / DMA

```c
HAL_I2C_Master_Transmit_IT(...)
HAL_I2C_Master_Receive_IT(...)

HAL_I2C_Master_Transmit_DMA(...)
HAL_I2C_Master_Receive_DMA(...)
```

Callback：

```c
HAL_I2C_MasterTxCpltCallback()
HAL_I2C_MasterRxCpltCallback()
HAL_I2C_ErrorCallback()
```

## 标准库对照

| 标准库 | HAL |
|---|---|
| `I2C_Init()` | `HAL_I2C_Init()` |
| `I2C_GenerateSTART()` | HAL Transaction 内部 |
| `I2C_Send7bitAddress()` | `DevAddress` 参数 |
| `I2C_SendData()` | `HAL_I2C_Master_Transmit()` |
| `I2C_ReceiveData()` | `HAL_I2C_Master_Receive()` |
| `I2C_CheckEvent()` | HAL 状态机内部 |
| 自己拼指定寄存器读 | `HAL_I2C_Mem_Read()` |
