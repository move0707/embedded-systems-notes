## 主线

标准库：

**RCC → GPIO → 外设 Init → ITConfig / NVIC → Cmd → 读写**

HAL + CubeMX：

**CubeMX 配置 → 生成 `MX_xxx_Init()` → HAL 启动/收发 → IRQHandler → HAL Handler → Callback**

真正需要重新适应的不是 GPIO、I2C、SPI 原理，而是：

**Handle / MSP / CubeMX / Callback / Blocking / IT / DMA**
