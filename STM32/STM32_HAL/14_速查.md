# 速查

## GPIO

| SPL | HAL |
|---|---|
| `GPIO_Init()` | `HAL_GPIO_Init()` |
| `GPIO_SetBits()` | `HAL_GPIO_WritePin(...SET)` |
| `GPIO_ResetBits()` | `HAL_GPIO_WritePin(...RESET)` |
| `GPIO_ReadInputDataBit()` | `HAL_GPIO_ReadPin()` |

## EXTI

| SPL | HAL |
|---|---|
| `NVIC_Init()` | `HAL_NVIC_SetPriority()` + `HAL_NVIC_EnableIRQ()` |
| `EXTI_GetITStatus()` | `HAL_GPIO_EXTI_IRQHandler()` 内部 |
| IRQ 写业务 | `HAL_GPIO_EXTI_Callback()` |

## 学一个 HAL 外设的顺序

1. 先在 CubeMX 找到它在哪个分类。
2. 看 CubeMX 生成的 `MX_xxx_Init()`。
3. 看 `xxx_HandleTypeDef` 的 `Init` 成员。
4. 找 `HAL_xxx_Init()`。
5. 找 Blocking / IT / DMA 三类 API。
6. 看 `HAL_xxx_IRQHandler()`。
7. 找对应 Callback。
8. 最后再去看寄存器/状态位为什么这样工作。
