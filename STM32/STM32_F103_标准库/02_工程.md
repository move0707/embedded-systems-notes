# 工程

## Keil

课程使用 **Keil MDK + STM32F10x Standard Peripheral Library**。

![[assets/ppt/s014_软件安装.jpg]]

*课程软件安装清单。*

安装链路：

**Keil5 MDK → 器件支持包 → 软件注册 → ST-LINK 驱动 → USB 转串口驱动**

这里真正需要记的是：Keil 是工程和编译环境，器件包让 Keil 认识具体 STM32 型号，ST-LINK 驱动负责调试下载。

## 新建

![[assets/ppt/s016_新建工程步骤.jpg]]

*课程给出的标准库工程创建步骤。*

标准流程可以压缩成：

**建文件夹 → Keil 建工程/选芯片 → 拷贝 Start/Library/User → 建 Group → 加源码 → Include Paths → `USE_STDPERIPH_DRIVER` → 配调试器**

如果缺 `USE_STDPERIPH_DRIVER`，标准库头文件的条件编译会不完整；如果 Include Paths 少了某个目录，常见结果就是头文件找不到。

## 架构

![[assets/ppt/s017_工程架构.jpg]]

*复位后从启动文件进入 SystemInit，再进入 main。*

启动链：

**Reset_Handler → SystemInit() → main()**

`startup_stm32f10x_md.s` 还定义了中断向量表，所以 IRQHandler 名称必须和启动文件中的向量名称完全一致。

## 结构体

标准库大量使用结构体初始化，课程专门把这一点拿出来讲：

![[assets/ppt/s035_C语言结构体.jpg]]

*结构体是标准库配置外设的核心写法。*

典型模式：

```c
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOA, &GPIO_InitStructure);
```

前几行只是在 RAM 里准备参数，最后的 `GPIO_Init()` 才把配置真正写进 GPIO 寄存器。

### `#define`

用有意义的名称替代常量，也适合集中管理经常修改的参数：

```c
#define ABC 12345
```

### `typedef`

给长类型起别名：

```c
typedef unsigned char uint8_t;
```

### `enum`

把一组有限取值组织起来。标准库中 `FunctionalState`、`FlagStatus`、`BitAction` 等都属于这种思路。

### 结构体

标准库最常见：先填成员，再把结构体地址交给 `xxx_Init()`。
