# 速查

## 初始化

| 外设 | 顺序 |
|---|---|
| GPIO 输出 | `RCC → GPIO_Init → SetBits/ResetBits` |
| GPIO 输入 | `RCC → GPIO_Init → ReadInputDataBit` |
| EXTI | `GPIO+AFIO 时钟 → GPIO → AFIO 映射 → EXTI → NVIC` |
| TIM 中断 | `RCC → ClockSource → TimeBase → IT → NVIC → Cmd` |
| PWM | `RCC → GPIO_AF_PP → TimeBase → OC → Cmd → SetCompare` |
| 输入捕获 | `RCC → GPIO 输入 → TimeBase → IC → Trigger/Slave → Cmd` |
| 编码器 | `RCC → GPIO 输入 → TimeBase → EncoderInterface → Cmd` |
| ADC | `RCC → GPIO_AIN → ADCCLK → ADC_Init → Channel → Calibration` |
| DMA | `AHB Clock → Channel → 地址/宽度/自增 → Cmd` |
| USART | `RCC → TX_AF_PP/RX_Input → USART_Init → IT/NVIC → Cmd` |
| 软件 I2C | `GPIO_OD → Start/Stop/Byte/ACK` |
| 硬件 I2C | `GPIO_AF_OD → I2C_Init → START → EV5/EV6/EV7/EV8` |
| 软件 SPI | `GPIO → SS/SCK/MOSI/MISO → SwapByte` |
| 硬件 SPI | `GPIO_AF → SPI_Init → TXE/SendData → RXNE/ReceiveData` |
| RTC | `PWR+BKP → LSE → RTCCLK → Sync → Prescaler → Counter` |
| IWDG | `WriteAccess → Prescaler → Reload → ReloadCounter → Enable` |
| WWDG | `PCLK1 → Prescaler → Window → Enable/Counter` |
| Flash | `Unlock → Erase → Program → Lock` |

## GPIO

**推挽：主动高 / 主动低**  
**开漏：主动低 / 高阻态**  
**复用输出：控制权交给片上外设**  
**模拟输入：给 ADC，关闭数字输入路径**

按键常见：

**上拉输入 + 按键接地 → 松开=1，按下=0**

## EXTI

**GPIO → AFIO → EXTI → NVIC → CPU**

同编号 GPIO 共用一条 EXTI Line：

**PA0 / PB0 / PC0 → EXTI0**

IRQ 中：

**判断 Pending → 处理 → 清 Pending**

## TIM

**更新频率：`Freq = CK_PSC / (PSC+1) / (ARR+1)`**

PWM：

**`Duty = CCR / (ARR+1)`**  
**`Reso = 1 / (ARR+1)`**

输入捕获：

**外部边沿 → CNT 锁存进 CCR**

编码器：

**A/B 相位 → TIM 硬件控制 CNT 加减**

## ADC

12 位：

**0 V → 0**  
**VREF → 4095**

转换时间：

**`TCONV = 采样时间 + 12.5 个 ADC 周期`**

多通道 + DMA：

**ADC Rank → DR → DMA → 数组**

## USART

**Start=0 → 数据 LSB First → Stop=1**

标志：

| 标志 | 含义 |
|---|---|
| TXE | 发送数据寄存器空，可写下一个 |
| TC | 最后一位也发送完成 |
| RXNE | 接收数据寄存器非空 |

## I2C

**空闲：SCL=1，SDA=1**  
**普通数据：SCL 低时改 SDA；SCL 高时读 SDA**  
**START：SCL 高时 SDA 1→0**  
**STOP：SCL 高时 SDA 0→1**  
**ACK：第 9 个时钟 SDA=0**  
**NACK：第 9 个时钟 SDA=1**

三种完整时序：

**写：`S → Addr+W → ACK → Reg → ACK → Data → ACK → P`**

**当前读：`S → Addr+R → ACK → Data → NACK → P`**

**指定读：`S → Addr+W → ACK → Reg → ACK → Sr → Addr+R → ACK → Data → NACK → P`**

## SPI

**SS↓ 开始，SS↑ 结束**

| Mode | CPOL | CPHA | SCK 空闲 | 第一个边沿 |
|---|---:|---:|---|---|
| 0 | 0 | 0 | 低 | 采样 |
| 1 | 0 | 1 | 低 | 更新 |
| 2 | 1 | 0 | 高 | 采样 |
| 3 | 1 | 1 | 高 | 更新 |

W25Q64 写：

**Write Enable → Erase/Program → Wait Busy**

## 低功耗

**Sleep：CPU 停，外设多数继续**  
**Stop：高速时钟停，唤醒后重新配时钟**  
**Standby：最深，唤醒后程序重新开始**

## 看门狗

**IWDG：不能太晚喂**  
**WWDG：不能太早，也不能太晚**

## Flash

**读：直接解引用地址**  
**写：Unlock → Program → Lock**  
**需要 0→1：先擦页**

## 排错

| 现象 | 先查 |
|---|---|
| GPIO 不动 | RCC、引脚、模式、有效电平、共地 |
| EXTI 不进 | AFIO、Line、Trigger、NVIC、IRQHandler 名称 |
| EXTI 一直进 | Pending 是否清、输入是否抖动/悬空 |
| TIM 周期错 | TIM 实际时钟、PSC+1、ARR+1 |
| PWM 没波形 | AF_PP、通道、CCR、重映射、TIM_Cmd |
| ADC 0/4095 | AIN、输入范围、通道、ADC 时钟、采样时间 |
| DMA 数组乱 | Channel、宽度、Inc、BufferSize |
| USART 乱码 | 系统时钟、波特率、8N1、共地 |
| I2C NACK | 地址、上拉、开漏、供电、SCL/SDA |
| SPI ID 错 | CPOL/CPHA、SS、MOSI/MISO、Dummy |
| RTC 不走 | LSE、RTCCLK、同步、BKP/PWR |
| Stop 唤醒后变慢 | 忘了恢复系统时钟 |
| Flash 数据不对 | 地址、页擦除、写宽度、是否覆盖程序区 |
