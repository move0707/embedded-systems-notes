# 使用

把整个 `江科大_STM32_Obsidian笔记_课件源码版` 文件夹复制到 Obsidian 仓库中即可。

推荐设置：

**设置 → 文件与链接 → 新附件默认位置 → 当前文件所在文件夹下的指定子文件夹**

后续自己截图时可以把附件目录设置为 `assets`。

本笔记中的课程图已经从上传的原始 PPT 渲染为本地 JPG，放在：

`assets/ppt/`

不依赖网络。

课程源码放在：

`源码/`

正文中的“视频源码”代码块直接来自上传的 **有注释版源码工程**，没有重新编写；完整源文件也保留在对应目录。

排版原则：

- 标题只保留 `GPIO / EXTI / TIM / ADC / I2C` 这类短标题。
- 流程能一行写清就用 `→` 横向写。
- 相关 PPT 图优先两张并排，不把所有内容无脑竖着堆。
- 长代码放在可折叠 Obsidian callout 中，阅读正文时不会挡住原理说明。
