## 学习顺序

**GPIO → EXTI → TIM → ADC/DMA → USART → I2C → SPI → RTC/PWR/WDG/Flash**

看标准库代码时固定先问四件事：

**时钟从哪来 → 引脚怎么接 → 外设内部怎么走 → CPU 什么时候读写/进中断**

代码只是把这四件事写进寄存器。
